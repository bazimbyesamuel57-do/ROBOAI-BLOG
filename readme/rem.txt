## 14. Styling: card and image hover effects (style.css)

**Goal:** the whole card grows slightly on hover, but the picture zooms only when the pointer is over the picture itself, not when it is over the rest of the card.

**How it works**
- Card: `.card` has `transition: transform 0.3s ease, box-shadow 0.3s ease`. `.card:hover` applies `transform: scale(1.04)` and a larger shadow. The transition sits on the normal state, so the card also animates back.
- Image: each card image sits in a wrapper `<div class="img-zoom">`. The wrapper has `overflow: hidden` and works as a frame that clips the zoomed image. The image has `transition: transform 0.4s ease`. The rule `.img-zoom:hover img { transform: scale(1.06) }` makes the zoom depend on hovering the frame, not on hovering the card.
- Rounded corners: the frame inherits the top corner radius of the card so the zoomed image does not show square corners.
- Accessibility: `@media (prefers-reduced-motion: reduce)` switches the transitions off for users who prefer less motion.

**Lessons / problems solved**
- `overflow: hidden` on the image itself does nothing; the clipping must be on a parent element.
- The hover must target the wrapper (`.img-zoom:hover img`), not the card (`.card:hover .card-img-top`), to get the "image only" behaviour.
- A global `img { height: 160px; object-fit: cover }` rule affected every image on the site (logo, slideshow); it was replaced by a rule scoped to `.card-img-top`.
- Duplicate rules and an unused `overflow` rule were removed during cleanup.
