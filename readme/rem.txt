2. Tech stack
Backend: PHP (mysqli, prepared statements), XAMPP
Database: MySQL / MariaDB, roboai_blog_db, port 3307
Frontend: HTML, CSS (own style.css / admin.css), Bootstrap 5.0.2 (cards, grid, dropdown), JavaScript (slideshow, admin side menu)
Tools: phpMyAdmin, Git (TODO: confirm), browser dev tools
3. Features built
Public site
home.php: slideshow (latest posts with images) plus post cards in a Bootstrap grid
post_categories.php: paginated post grid, category dropdown filter, text search (title and excerpt), filters kept across pages
post_details.php: full post, author box (photo and bio), comments
contact.php: contact form with validation, saved to contact_us
about_us.html
Admin area (/admin)
admin_login.php / admin_register.php: hashed passwords (password_hash / password_verify), session started on login
admin_dashboard.php: latest posts overview and side menu
admin_posts.php: post table, filters (title, author, category, status, date), pagination, edit and delete
create.php: new post with image upload, author selection, new or existing category, draft or published status
add_author.php: new author with photo, returns to create.php with the draft kept in the session
edit.php: update a post, replace the image (old file deleted)
delete.php: delete the post and its image file (comments removed by ON DELETE CASCADE)
admin_contactfeed.php: list of contact messages
4. Data model (tables)
posts: post_id, category_id, admin_id, author_id, title, excerpt, content, author_name, status, published_on, media
categories: category_id, category_name
author: author_id, author_name, author_bio, author_image
admin: admin_id, name, email, password (hash)
comments: TODO (add columns)
contact_us: contact_us_id, firstname, lastname, email, subject
Relations: category 1-n posts, author 1-n posts, admin 1-n posts, post 1-n comments (cascade delete)
5. Challenges and solutions (use for the "challenges" slide and the abstract)
Challenge	Cause	Solution
Images broke after moving files into admin/	Relative paths resolved against the new folder	Root-relative URLs for display (/ROBOAI/images/...); ../images/ for saving files on disk; DB stores images/...
Upload failed with "No such file or directory"	Mixed up disk paths and URL paths	Separate disk path from the value stored in the DB
Cards not laid out in a grid	Wrongly closed row div; later box-sizing: inherit made Bootstrap columns overflow	Fixed the markup; added html { box-sizing: border-box; }
Plain-text passwords and SQL built from user input	First version of login and register	Prepared statements and password_hash / password_verify
Form never saved to the DB	Submit button had no name attribute	Added name="submit"
Native dropdown opened upwards and was too long	Browser decides the direction of a <select>	Bootstrap dropdown with a max height and scroll
Post "view" link broken in admin	Relative link pointed inside admin/	../post_details.php
