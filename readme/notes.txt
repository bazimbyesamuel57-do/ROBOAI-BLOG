bugs
The photo path goes into the wrong variable. After the upload you write $media = 'images/authors/' . $new_name;, but the INSERT uses $author_image. That one stays '', so the photo file is saved but the database never records it.
enctpe is misspelled in the <form> tag. Without enctype="multipart/form-data", the file never reaches $_FILES, so every author is saved without a photo and you get no error.
The submit button has no name. Your PHP runs only if (isset($_POST['submit'])), so clicking Save does nothing. This is the same problem create.php had at the start.
The redirect: 'add_author.php?saved=author_id= ?' is a broken address. Use ?saved=1. (If you want the new id, mysqli_insert_id($conn) gives it.)
The success note is red. It should be green.
accept="image/author/*" isn’t a valid value. Use image/*.
<textarea type="text">. A textarea has no type attribute.
No check after mysqli_prepare. A failed prepare would give a confusing error on the next line.
